# HAuto Recruiting Assistant (채용 업무 자동화 비서 V3)

HAuto는 헤드헌팅 및 채용 업무의 생산성을 극대화하기 위해 **사내 시스템, 사람인, 잡코리아, Google Sheets, Notion, Gemini AI**를 하나로 연결하는 강력한 크롬 확장 프로그램 패키지입니다. 

---

## 📂 파일 구성 안내

- `manifest.json`: 크롬 확장 프로그램 실행 및 권한 정의 (V3 규격)
- `popup/`: 확장 프로그램 팝업 설정창 UI 패키지 (HTML/CSS/JS)
- `scripts/content.js`: 채용 플랫폼 및 사내 시스템 화면에 자동화 버튼을 동적으로 주입하고 정보를 스크래핑하는 스크립트
- `scripts/background.js`: 백그라운드에서 Gemini API를 호출하고 Google Sheets/Notion으로 데이터를 송수신하는 통신 허브
- `GoogleAppsScript.js`: 구글 스프레드시트 자동 엑셀화 및 이메일 자동 발송을 위한 GAS 가이드 소스코드

---

## 🛠️ 1단계: 크롬 확장 프로그램 로컬 설치 방법

1. 구글 크롬 브라우저를 열고 주소창에 `chrome://extensions` 입력 후 엔터를 누릅니다.
2. 우측 상단의 **[개발자 모드]** 토글 스위치를 활성화(On)합니다.
3. 좌측 상단에 새로 생긴 **[압축해제된 확장 프로그램을 로드합니다]** 버튼을 클릭합니다.
4. 로컬 PC에 저장된 본 프로젝트 폴더(`d:\Work\AI\HAuto`)를 선택하여 로드합니다.
5. 크롬 주소창 우측의 퍼즐 조각 아이콘을 눌러 **HAuto Recruiting Assistant**를 고정(Pin)합니다.

---

## 🔑 2단계: 클라우드 무료 연동 설정

확장 프로그램 아이콘을 클릭하여 설정 탭에서 아래의 API 정보를 기입한 뒤 `[설정 저장]`을 누릅니다.

### ① Gemini API Key (AI 분석용)
1. [Google AI Studio](https://aistudio.google.com/)에 구글 계정으로 로그인합니다.
2. `[Get API Key]` 버튼을 눌러 API 키를 무료로 생성하고 복사하여 HAuto 설정창에 붙여넣습니다.

### ② Google Sheets 연동 (실시간 자동 엑셀화)
1. 함께 제공된 `GoogleAppsScript.js` 파일의 내용을 전부 복사합니다.
2. 연동할 구글 스프레드시트를 만들고 상단 메뉴의 **[확장 프로그램] > [Apps Script]**를 엽니다.
3. 복사한 코드를 붙여넣고 상단 **[배포] > [새 배포]**를 선택합니다.
4. 유형 선택: **웹 앱 (Web App)**을 지정합니다.
5. 설정 권한: **'나(본인 계정)'**으로 실행하고, 액세스 권한은 반드시 **'모든 사용자 (Anyone)'**로 지정하여 배포합니다.
6. 배포 성공 시 나타나는 **[웹 앱 URL]**을 복사해 HAuto 설정창의 `Google Sheets URL` 란에 등록합니다.
7. *(선택)* 구글 시트에서 후보자 행의 진행상태 열을 `서류합격`, `서류불합격`, `면접탈락` 등으로 바꾸면 본인의 Gmail을 통해 개인화된 안내 메일이 후보자에게 자동으로 발송됩니다.

### ③ Notion 연동 (이력서 아카이브 & 검색용 데이터베이스)
1. [Notion API Developer Portal](https://www.notion.so/my-integrations)에 접속하여 새 API 통합(Integration)을 만들어 토큰을 복사해 HAuto 설정창에 넣습니다.
2. 노션에서 후보자 관리용 데이터베이스 페이지를 만들고 다음 열을 생성합니다: **이름(제목), 연락처(텍스트), 이메일(이메일), 보유 기술(텍스트), 경력사항(텍스트), 진행상태(선택), 등록일(날짜)**.
3. 데이터베이스 우측 상단 `...` 버튼을 눌러 생성한 API 통합 앱에 페이지 편집 권한을 연결(연동)해 줍니다.
4. Notion 데이터베이스 주소에서 `notion.so/workspace/` 뒷부분의 32자리 고유 데이터베이스 ID를 추출하여 HAuto 설정창에 기입합니다.

## 🤖 3단계: 100% 팩트 기반 프롬프트 제어판 활용법

HAuto는 AI 분석 시 존재하지 않는 정보를 지어내는 현상(환각)을 완벽하게 차단하며, 사용자가 직접 지시어를 통제할 수 있습니다.

1. **AI 개별 옵션 관리**:
   - 확장 프로그램 내 `AI & 프롬프트` 탭에서 비용 및 필요도에 맞추어 각 단계별 AI 기능을 활성화/비활성화 할 수 있습니다. (비활성화 시 API 요금이 일절 발생하지 않습니다.)
2. **프롬프트 보기 및 실시간 커스텀 (`🔍` 버튼)**:
   - 각 단계 카드 옆의 `🔍` 버튼을 누르면 실시간 프롬프트 템플릿 수정이 가능합니다. 
   - 문구를 고친 뒤 `[저장]`하면 이후 실시간 연동부터 즉시 본인의 지시어가 반영됩니다.
3. **완성형 프롬프트 원클릭 복사 (`[최종본 복사]` 버튼)**:
   - 본문의 `{{JD}}`, `{{이력서}}`, `{{자소서}}` 변수가 현재 분석 대상자의 팩트 텍스트로 깔끔하게 치환된 프롬프트 전체가 복사됩니다.
   - 복사된 최종 결과물을 **웹 ChatGPT, Claude, Gemini 웹 사이트 등에 직접 붙여넣어 최상의 성능 비교와 다양한 외부 AI 실험을 수행**해볼 수 있습니다.
   - 프롬프트가 망가질 경우 언제든 `[기본값 초기화]`를 클릭해 복구 가능합니다.

## 🚀 4단계: 실무 사용 흐름 (Flow)

1. **사내 JD 감지**: 사내 시스템에 기획된 JD 페이지를 열고 `[🎯 현재 JD 타겟 지정]` 버튼을 누르면 기준 JD가 로컬 브라우저에 임시 기억됩니다.
2. **포탈 인재 검색**: 사람인/잡코리아에서 후보자 이력서 상세페이지를 열면 우측에 **HAuto 어시스턴트** 패널이 노출됩니다.
3. **AI 매칭 분석 및 제안문 작성**: `[후보자 매칭 분석 (2단)]` 및 `[제안문 작성 (3단)]`을 누르면 AI가 오직 팩트만을 대조하여 적합도 점수와 제안 메시지 초안을 팝업창으로 바로 제어해 줍니다.
4. **구글 시트/노션 실시간 저장**: `[구글시트/노션 저장 (4단)]`을 누르면 화면상의 이름, 연락처, 이메일 등이 1초 만에 구글 시트의 한 행으로 자동 엑셀화되고, 동시에 노션 데이터베이스에 후보자 상세 이력 정보 페이지가 실시간 연동 생성됩니다.
5. **사내 메일 전송**: 구글 시트에서 상태를 변경하여 메일 양식이 자동 팝업되면 발송 버튼만 눌러 업무를 마칩니다.
